Launch App How it works

From PDF to a cited answer, in six small steps.

Every question follows the same transparent path. Nothing reaches the model unless retrieval finds it first.

01

Upload PDFs

Official scheme guidelines land in data/schemes or through the in-app uploader.

02

Extract and chunk

pypdf reads each page, split into overlapping chunks so nothing is cut mid-sentence.

03

Embed

Every chunk becomes a vector with OpenAI embeddings, meaning captured as numbers.

04

Index locally

Vectors live in ChromaDB with file and page metadata attached to each one.

05

Retrieve

Your question finds its closest passages, ranked by similarity and filtered for quality.

06

Cited answer

The model answers only from those passages and names the exact document and page.

The honesty rule: if retrieval finds nothing relevant above the similarity threshold, GovAssist tells you outright instead of guessing. The model never sees a whole document, only the handful of passages that matched.

Two rules before you upload.

Rule 01

Text-based PDFs only

Open the file and try selecting a sentence with your cursor. If you cannot select or copy text, it is a scan, and ingestion will reject it. OCR is out of scope by design.

Rule 02

Name files descriptively

The filename becomes the scheme name shown in every citation, so make it readable at a glance.

pm_kisan_guidelines.pdf

Why trust the answer?

Only your documents

The model has no outside knowledge of schemes. What you upload is the entire universe it can speak about.

Page-level citations

Every answer lists the exact document and page it drew from, pulled from real retrieval metadata.

Admits what it lacks

If the passages do not cover your question, GovAssist says so plainly instead of inventing eligibility criteria.

Run it locally in three commands.

# install dependencies $ pip install -r requirements.txt # add your API key, then index your PDFs $ cp .env.example .env && python ingest.py # start asking questions $ streamlit run app.py

Needs an OpenAI API key in .env. Works through any OpenAI-compatible provider too.

GovAssist provides information from the uploaded documents and should not be treated as official government advice. Always verify current eligibility and application details with the relevant government authority.
